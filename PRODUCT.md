# GTF Studio

<!-- impeccable:product-schema 1 -->

## Platform

Web, with responsive touch controls and an installable PWA. Native app store binaries are outside this frontend release.

## Purpose

Create, edit, save locally, present, and export visual designs and presentations without an account or backend service.

## Confirmed constraints

Next.js App Router, strict TypeScript, Tailwind v4, Konva, typed mock and HTTP services, a versioned framework-independent document model, IndexedDB, automated tests, dark mode, and accessible loading/error/retry states. Pages remain server components; browser persistence and editor interactions use bounded client features.

## Brand commitments

The user confirmed GTF Studio as the name and requested a Dropbox-inspired landing structure, Adobe Express and Microsoft Designer-like clarity, Canva-like editing workflows, and GTF Technologies' cyan/pink palette.

## Release boundary

Cloud authentication, billing, real-time collaboration, remote share links, AI services, and cloud storage are unavailable and must not appear as working controls. No backend credentials are required. Original geometric templates are bundled. Browser storage is device- and origin-local, with downloadable document backups.
